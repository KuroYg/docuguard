# Cookie policy

**Product:** DocuGuard preview with optional hosted accounts
**Last updated:** 19 November 2026

## Cookies and tracking

DocuGuard does not set cookies. It does not use analytics, advertising pixels, or cross-site tracking. When hosted accounts are configured, the Supabase client stores the authentication session in browser `sessionStorage` for the current tab. This is authentication storage, not a tracking cookie. The notice dismissal is also held in session storage and may appear again after the tab closes.

## Local processing

Repository path, revision inputs, and analysis results stay in the current tab and are sent only to the local DocuGuard API when you start an analysis. Press **Clear this session** to clear visible inputs and results. Browser extensions and development tools are outside DocuGuard's control.
